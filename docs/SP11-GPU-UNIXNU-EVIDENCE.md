# SP11 GPU UniXNU study: evidence register

This file holds appendix C of [SP11-GPU-UNIXNU.md](SP11-GPU-UNIXNU.md), kept in its own file so that neither document grows
without bound. The two files are one study: the body there cites rows here as `[LABEL Uxx]`, and
`tools/test-sp11-gpu-unixnu.py` reads them together.

One row per cited fact. Source is `KEY path:lines` with the key and path prefix from
[section 0.2](SP11-GPU-UNIXNU.md#02-citation-keys); Token is
a string that must occur in those lines, so a moved or mis-numbered range fails the test instead of misleading a reader.
Basis `design` is what the cited text itself states, `device` is a third-party device record kept in the cited file, and
`host` is a host-side record. Row ids are stable keys; a gap in the numbering is a row that was dropped as unused.
