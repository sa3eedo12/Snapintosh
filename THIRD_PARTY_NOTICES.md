## Apple material

Snapintosh interoperates with Apple software that it does not redistribute.
These are produced locally from the user's own KDK, kernelcache and macOS
install, and are not in this repository:

- disassembly of Apple kexts and IO80211Family ABI dumps;
- the reconstructed private class headers `*26A428.h` used by the AdrenoX2 /
  AdrenoDisplay kext and the QCC2072 driver (the build scripts stop with an
  error naming any that are missing);
- Adreno binaries compiled from Apple's WindowServer shaders
  (`render-shaders*.json`, `p7-shaders*.json`).

XNU and other Apple Open Source projects are referenced by link only; no
APSL-2.0 code is included.
